# SolidWorks 联合工作流

从图纸和任务要求确定零件清单、配合关系、运动范围与出图范围。默认名称、窗口数量、图纸语言和表格按当前项目要求确定。能力及版本支持以父技能的能力清单和运行证据为准。

1. **零件建模**。记录标注、几何推导和补设尺寸各自的依据，完成参数化特征、材料与重建检查。读取 [建模与装配](references/modeling.md)。
2. **装配体**。核对组件引用、实际实例、配合、干涉和运动自由度。保存并重开检查。
3. **原生动画**。在可运动的最终装配中建立算例。按 [原生动画](references/native-animation.md) 验证保存重开后的关键时刻和动作，按需求使用 SolidWorks 原生导出视频。
4. **工程图**。为需求指定的零件或装配创建关联图纸，按 [原生工程图](references/drawings.md) 核对视图、剖切、尺寸与 BOM。

局部修订以当前文件为源，只更新受影响的模型、引用、动画和工程图。交付前核对各文件对应的源版本以及实际保存、重开和验收状态。
