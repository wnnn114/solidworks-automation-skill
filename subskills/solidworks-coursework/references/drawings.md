# 原生工程图与装配 BOM

## 出图范围与关联

根据当前需求列出出图对象、图幅、视图、比例、投影法和标注要求。按项目标准选择实际图框和标题栏属性。尺寸应关联实际模型尺寸、边或面，保存重开后检查尺寸值与悬空状态。

保持源模型与图纸间的版本对应。生成 PDF 后核对漏标、重叠、引线、标题栏和剖视。只读导出时核对源文件和依赖未被保存或覆盖。

## 偏置零件的剖切线

剖切位置由模型中实际孔槽位置确定。在已验证的 SW2026 视图草图上下文中，可用以下坐标关系：

```text
图纸点 = 模型点经 IView.ModelToViewTransform 变换
视图草图局部点.xy = (图纸点.xy - IView.Position.xy) / IView.ScaleDecimal
```

读回剖切线端点及剖视对象，确认截到预期特征。删除失败剖视时检查残留的父视图草图线，并用正确的 `SelectData.View` 限定选择。

动画过程中的条料或废料拉大图面范围时，可通过图纸目标视图的 `IDrawingComponent` 隐藏对应实例。重新读取 `GetOutline`，按可见轮廓调整视图位置，复核相关尺寸和注释。剖视标题含 `<VLLABEL>` 或 `<VLSCALEV>` 字段时，移动原有注释并保留字段绑定。

## 装配 BOM 与序号

按实际装配层级、组件类型和实例数生成原生 BOM。按图纸要求决定工艺演示组件是否计入明细表。材料、质量等列从实际模型属性取得，重开后回读原生关联。

SW2026 个别 GB 模板的“代号”是普通列。零件号、序号和数量的列类型参考本机类型库，并读回各行实际组件。气泡序号使用装配上下文实体与图纸视图选择，必要时借助 `GetCorrespondingEntity`。保存重开后核对行号、数量和气泡指向。
