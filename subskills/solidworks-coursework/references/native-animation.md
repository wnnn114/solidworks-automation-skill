# SW 原生动画与录制

本经验覆盖 SW2026 SP0.0 中具有真实配合的平移机构、原生 Animation 时间轴和 SW 原生视频导出。不包含任意转动轨迹、复杂接触动力学或跨版本自动化承诺。

## 先区分算例类型

- Animation 时间轴用于明确的机构动作与位姿演示，验收重点是原生键、保存重开后的独立回放及实际显示结果。
- Basic Motion / Motion Analysis 若任务要求接触、载荷或物理结果，应验证许可证、求解器、结果对象及结果是否过期。不能由本案例的动画成功声称获得动力学结果。
- 本次 Animation 的类型值为 1，不要求仿真结果对象。不要把马达算例的 `require_results=True` 门槛不加区分地套在键帧动画上；具体枚举应从当前安装类型库核实。

优先读取父技能的 Motion 与装配参考并复用封装。没有可用写键 API 时，可使用本次实际验证过的 SW AutoKey 加原生拖动路线；它仍需当前 GUI 状态和回放证据，不能只靠文档声明。

## 动作计划

把运动对象、方向、行程、先后顺序、停顿区间和安全过渡写成时间表。说明每个动作由什么实际机构实现；需要上料或人工取出时如实表达，不虚构不存在的机械手或顶杆。

通过透明显示或适当剖视呈现内部配合。制件与废料从真实分离位置沿实际通道排出，不用瞬移、穿透、出现或消失掩盖运动。部件在相机之外可暂不展示，但必须能解释其物理路径。

初始装配位置在“模型”页真实求解并保存，再建立默认名称的运动算例。不要用固定的历史名称，如 `运动算例 2`，去覆盖新任务的算例。

## AutoKey 与原生拖动的实测要点

1. 检查当前算例真实 AutoKey 状态。公开接口未提供具名开关时需要当前工具栏或 UI 状态证据；不能把某个“录制”命令号猜作 AutoKey，也不能保存一个总返回 True 的确认函数。
2. 在目标时间通过原生拖动算子改变组件位置。本次使用 `IDragOperator` 的 `AddComponent → BeginDrag → DragAsUI → EndDrag`，目标移动受装配可达关系校验。
3. 本次拖动助手仅支持平移。SW 变换数组中的平移位于索引 9～11、单位米；相对平移矩阵须使用单位旋转，不能再次叠加组件已有旋转。旋转、缩放轨迹应另找适合的原生方案并验证。
4. 同一位置保持或回零时，仅设置相同值可能没有新键。本次在同一时间栏做经过可达性检查的小幅往返拖动，再返回目标位置促成保持键。临时偏移不能超行程、碰撞或改变时间栏；若不能找到安全偏移，就用其他可验证的原生键操作。
5. 稀疏键只可删除确实冗余的等速共线平移键。必须保留速度转折、停顿起止和最后运动端点，并检查 SW 实际插值是否仍符合时间表；不能仅凭离线线性计算删键。

不要把逐帧脚本赋 `Transform2` 得到的屏幕变化视为已写入时间轴。录制期间使用的位姿设置、拖动，以及验收期间只读回放应明确分开。

## 保存重开后的独立回放

完成原生录制与计算后保存装配，关闭并重开本轮文档，再按实际默认名称绑定已保存的算例：

- 以逆序、交错顺序跳到关键时间，避免只验证顺序播放时残留的上一帧位置。
- 采用 `Stop → SetTime → 等待实际显示状态稳定 → 读取实际变换`。目标时间已到达导致 SetTime 无操作时，应以实际时间与稳定读回判断，不简单把 False 当成功。
- 验收路径禁止调用位姿 setter 或拖动帮助“达到预期”。读取真实显示变换并与计划对比，检查静止件、透明度及工艺对象状态。
- 合并过的运动区间增加内部采样，特别检查停顿、复位及末端保持。误差容差应由当前机构精度确定，不把案例的阈值强加给新任务。
- 若 UI 出现“更新初始动画状态”对话框，核对 SW PID、完整标题及上下文后决定是否保留原初始键。不能按任意弹窗自动点击；不确定时停止本次录制并说明实际状态。

只有此时的实际回放通过，才能称原生算例已经保存并可播放。单独的 `Calculate=True`、时间轴图标或计划矩阵都不足以证明。

## SW 内置视频导出

本次实际使用 `IMotionStudy.SaveToAVI`，方法名称不限定最后一定是 AVI 容器。SW2026 的导出参数实测 MP4 输出类型值为 7、AVI 为 1；从当前类型库核实后再用，不跨版本猜测。

设置并回读输出类型、帧率、尺寸、比例及完整时间范围。按当前报告决定数量、时长和格式；本次 25 秒、24 fps、1920×1080 只是案例值。

原生导出后等待文件写入稳定，记录文件 SHA256。用解码器完整读取视频并检查关键动作画面；允许解码和抽帧用于 QA，不用外部编码、拼接或视频生成工具替代 SW 成果。容器头存在或文件能打开都不能代替完整解码。

帧数需考虑包含首尾端点的导出行为：本次名义 25 秒导出 601 帧，24 fps 对应解码时长约 25.0417 秒。先检查算例时间范围与端点是否正确，不为凑整数时长在外部裁剪重编码。

修正装配结构或运动后，旧视频应视为过期；重新回放、原生导出并同步报告中的相关图片。只调整未影响运动的工程图表格时，无需重建原生动画。
