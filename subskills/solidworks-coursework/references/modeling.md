# 建模与装配

适用于按二维图纸及工艺资料创建真实参数化零件，再装配成可运动模具。这里的执行方式来自 SW2026 SP0.0 案例，其他版本应重新检查接口与返回值。

## 尺寸依据与设计取值

建模前记录每个未注参数的来源类别：原图明确标注、跨视图推导、几何约束、标准或厂家规格、经授权补充设计。计算值保留公式、单位和输入来源。不得由图片像素比例估算孔径、模架厚度或行程；找到相似模架也不能证明它就是当前图的规格。

本次原图缺少孔径、孔位、板厚、步距和行程，网上标准无法唯一恢复整套原设计。最终在用户明确授权后才进行补充设计。这个授权不自动延伸到以后新任务。

机构设计需要贯通以下尺寸关系，不能分别为每个零件取一个看起来合理的值：

- 制件轮廓、排样方向、冲孔与落料工位、材料厚度及送料步距。
- 凸凹模单边间隙、工作段高度、固定卸料间隙、冲裁进入量及排料通道。
- 模板累积高度、闭合和开模位置、导柱导套有效接触长度、挡料与越障高度。
- 螺钉有效啮合、盲孔底部余量、销钉安装深度，以及局部孔槽是否相交。

缺少关键依据时保留未定项并继续不依赖它的工作，必要时询问；不能把任意设计取值包装成标准规定。

## 单窗口与默认命名

1. 记录当前会话用户文档；每次只新建一个本轮可见零件。
2. 创建后立即读取实际 `GetTitle`。默认标题可能跳号、带扩展名或在重启后重复，不得自己递增计数、补齐序号或按用途重命名。
3. 用独立的“用途 → 文件路径 → 实际标题”映射管理文件。用途可写中文元数据，但不能改零件、特征、实例或配合的名称。
4. 首次保存前检查目标是否存在。如果是另一零件则不得覆盖；先查明会话默认名称冲突，在已授权的目录规则内处理，无法同时满足时说明冲突。
5. 保存并登记校验结果后关闭本轮零件窗口，再建下一个。后台源引用应按所有权和依赖处理，不执行无差别 CloseAll 或 Quit。

不要把所有源文件长期开成可见窗口来批量建模。COM 写操作保持串行；离线资料读取、数值计算不依赖 CAD 活动文档时才可并行。

## 草图、特征与材料

- 草图用真实驱动尺寸与水平、相切、同心、对称等关系达到合理约束状态，不用批量 Fix 代替设计约束。
- 回读草图约束状态、悬空关系、消费它的特征，以及关键尺寸。`ISketch.GetFeature` 无返回时，可在创建前后特征集合中定位唯一新增草图，而不是重命名它。
- 内部 API 长度通常为米；零件尺寸记录可为毫米。明确草图局部坐标、模型坐标和装配坐标，不能混用。
- 原厂螺纹库自带的单个固定基准点，只有在核对库文件、真实消费特征及驱动参数后，才可作为有记录的例外；不能据此放宽用户草图的 Fix 检查。
- 从实际中文版材料库赋材，回读材料名、密度和质量。没有数据时不补造强度、硬度或热处理参数。
- 明确区分实体内螺纹、持久装饰外螺纹与螺旋油槽。不能把油槽叫作螺纹，不能把装饰螺纹宣称为实际螺旋牙型。
- 质量题以当前 SW 质量属性为准，核对 `质量 = 体积 × 密度`，按题目单位和保留位数作答。必要时用较高质量属性精度重建并独立计算核对，不通过调密度凑答案。
- 派生修改题应保留真实源零件关联；不能复制成无关联的独立外形后声称是原模型修改。

父技能已有包装优先复用。未封装的动态 COM 只有传入参数时才先 `_FlagAsMethod(name)` 再调用；无参数成员须兼容属性/方法。不要把所有成员都加括号，也不要盲目将属性标成方法。

## 装配完成后统一核验

以实际工艺确定基件、配合和运动自由度。静止件可完全定位；运动上模、滑指等保留指定方向和行程。零件数量从“用途需求清单”和“实际组件路径/实例”双向对照，避免遗漏仅在局部图中出现的挡料销等小件。

统一检查：配合错误与过定义、非预期松动、需要保留的移动方向、端点和关键中间位置、固定件漂移、排料可达性，以及干涉。静态摆出多个位置时应让实际配合求解参与；动画阶段还必须单独验证时间轴，二者不能互相替代。

装饰外螺纹的名义圆柱与攻丝孔可能产生啮合表示重叠。只有实体身份、空间范围、孔深及啮合关系均匹配时才能单独声明；不得统一忽略所有螺钉干涉，也不得报告“零干涉”。未解释的相交必须修正。

工艺演示用的制件、孔料和条料与模具结构零件分开统计，是否排除结构 BOM 依任务判断。需要大量工艺实例时，不能让它们改变装配结构零件数量的解释。

## 中断和只读操作

中断后先检查活动文档、未保存状态、已有特征和最后落盘哈希。若当前默认名零件已有部分特征，核对后补剩余步骤；不要重跑整段造成重孔、重复线程或重复算例。

恢复旧索引时，当前文件与历史哈希不同应先识别用户后续编辑。历史哈希用于判断版本，不是恢复旧文件覆盖当前文件的理由。

只读装配有时因加载或缓存出现 `GetSaveFlag=True`。不能直接保存消除此标志；本次允许继续只读出图的条件是确为只读、磁盘源与依赖哈希不变，组件路径、名称、变换及抑制状态的运行快照也完全不变。条件不满足就查明原因，不能单凭“只读”字样判定安全。
